1. create a git repo and clone in local
2.create a code.py file and add code to it . (it will save a csv file to a new "data" folder)
3.do a git push and commit before initializing DVC.
#pip install dvc
4.Now we do "dvc init" (creates .dvcignore, .dvc)
5.Now do "mkdir s3" to make a s3 directory 
6.Now we do "dvc remote add -d myremote s3"
7.Next "dvc add data/"
8.dvc commit and dvc push
9.Do a git commit -push to mark this stage as first version of data
10. Now make changes to mycode.py to append a new row in data, check changes via "dvc status"
11. again dvc commit and dvc push
